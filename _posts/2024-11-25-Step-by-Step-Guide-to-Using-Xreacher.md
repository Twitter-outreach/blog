This guide provides detailed instructions for setting up your account, scraping leads, starting and managing campaigns, and monitoring progress using Xreacher.

## 1. Setting Up Xreacher

### Navigate to the Accounts Page:
- Add your X account:
  - Add an account using AUTH and CT0 tokens.
  - Ensure the account is verified and has a blue checkmark.
  - Premium verification is available for US$8/mo.

## 2. Scraping Leads

### Go to Campaigns or Leads section:
- Adding new leads:
  - Use the scraper to add new leads.
  - Enter the X account’s username you want to scrape followers from.
- Apply filters:
  - Use filters to target a specific audience.
  - Apply keywords and location filters.
- Start scraping process

## 3. Starting Campaigns

### Go to the Campaigns tab:
- Select leads list for your campaign:
- Craft messages:
  - Craft personalized messages with AI-generated first names.
- Select account(s):
  - Pick the account(s) you want to use for your campaign.
- Set a message limit:
  - Set a message limit (up to 450 DMs/day for the pro version).
- Add stack tag:
  - Use stack tags for multi-account management.

## 4. Running Campaigns

- Monitor campaign progress:
  - Use the dashboard to monitor campaign progress.
  - Multiple accounts can be added to one campaign.
- Join the affiliate Program:
  - Xreacher offers an affiliate program with a 40% commission.
- Contact support:
  - Reach out via Telegram for questions or support.

## Action Items

- Add verified X account(s) to Xreacher.
- Scrape leads using the Scraper.
- Apply filters to target a specific audience.
- Start a campaign with the selected lead list.
- Monitor campaign progress.
- Sign up for the affiliate program.
